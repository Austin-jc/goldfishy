Why GoldFishy exists

Notes apps make you choose between a pile you can't find anything in, a filing system you won't maintain, or a cloud AI you shouldn't have to trust. GoldFishy refuses all three.

Organizing is toil

You write. It files.

Folders, tags, and titles are upkeep most people abandon. GoldFishy's local AI does the librarian work — titling, tagging, suggesting where things belong — a few seconds after you stop typing, and never moves anything without asking.

Capture is lossy

Faster than forgetting.

Thoughts arrive mid-task and mid-meeting. ⌘⇧N opens a capture window from anywhere; hit Enter and get back to what you were doing. Even the todos buried in your prose get found and turned into reminders.

Cloud AI = your notes, their servers

Private by architecture.

Notes are some of the most personal data you have. Every feature — semantic search, tagging, summaries — runs on models on your machine. The app works fully offline, forever.

Features

A real markdown notepad first; a quiet AI layer on top. Everything below works without an account or an internet connection.

Search by meaning

"Flight stuff" finds your airline booking note even if it never says those words. Local embeddings, instant keyword search too.

Auto-tagging & titling

Untitled brain-dumps get titles; every note gets a few reusable tags. AI tags are visibly distinct and one click to remove.

Action items & reminders

"Send the report by Friday" inside a note becomes a proposed reminder — with the date parsed. Nothing is scheduled until you accept.

Global quick capture

⌘⇧N from any app opens a tiny capture window. Type, Enter, gone — the AI titles and files it later.

Markdown WYSIWYG

Type markdown, see rich text. Code blocks with highlighting, task lists, images by drag-drop or paste. Stored as plain Markdown.

Command palette

⌘K for fuzzy search across everything — keyword or semantic — plus >-prefixed commands, VS Code style.

Auto-bullet & summaries

One click turns a stream-of-consciousness dump into tidy bullets, or summarizes a whole folder or tag into a paragraph.

Tidy up duplicates

Finds clusters of near-identical notes and offers to merge them into one — tags and reminders carried over, originals in Trash.

Nothing is ever lost

Version history with restore, a 30-day Trash, scheduled markdown backups, and lossless export — your notes are never locked in.

Works when you don't

AI runs only after you stop typing — embeddings first, heavier language-model work only while you're idle.

Never interrupts

No pop-ups, no blocking modals. Results fade in; a status line in the sidebar shows exactly what's being processed.

Asks before acting

Tags are removable, filing is a suggestion, reminders start as proposals, and every AI rewrite is snapshotted for undo.

Quickstart: enabling the AI features

Search, folders, tags, and the editor work out of the box — semantic search just downloads its ~80 MB understanding model on first launch, automatically. The language-model features (tagging, titling, summaries, action items) need a local model. The easiest path is Ollama — about five minutes, once.

Build GoldFishy

Prereqs: Rust toolchain, Node 18+, Xcode command-line tools (macOS).

git clone https://github.com/Austin-jc/notepai && cd notepai
npm install
npm run tauri build

Install Ollama

Download it from ollama.com and run the installer, like any app.

Get a model

In Terminal (about a 2 GB download):

ollama pull llama3.2

Connect GoldFishy

Settings → AI Engine → External server. Server URL http://localhost:11434, model name llama3.2 → Test connection → Save. Auto-tagging starts working in the background immediately.

"Localhost"? "Server"? Despite the words, all of this happens inside your own computer. The only internet GoldFishy ever uses is downloading models — after that, everything is fully offline.

Alternative: skip Ollama and let GoldFishy run the model itself

GoldFishy can manage a llama-server sidecar directly: brew install llama.cpp, then in Settings choose Local model (llama.cpp), browse to the llama-server binary (usually /opt/homebrew/bin/), paste a HuggingFace repo like bartowski/Llama-3.2-3B-Instruct-GGUF, and click Download. The app spawns and manages the server on demand.

Prefer to stay in control? Use Manual mode

Settings → Processing lets you switch from Full Auto to Manual Only — the AI then runs only when you click Organize or Auto-bullet, and a Re-index button lets it catch up on the backlog whenever you choose. Every automatic behavior (tagging, titling, folder suggestions, action extraction) also has its own toggle.
